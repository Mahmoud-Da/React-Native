*** 2- Borders ***
### Lecture Notes: Borders and Basic Styling in React Native

---

## 1. Cleaning Up the App Component

### Concept

* A parent `View` is used as a container.
* The container:

  * Fills the entire screen using `flex: 1`.
  * Centers all child components using:

    * `justifyContent: "center"` (vertical alignment)
    * `alignItems: "center"` (horizontal alignment)

### Step 1: Create a Centered Container

#### Code

-------------------code----------------------
import { View } from "react-native";

export default function App() {
  return (
    <View
      style={{
        flex: 1,
        justifyContent: "center",
        alignItems: "center",
      }}
    >
    </View>
  );
}
-------------------code----------------------

---

## 2. Using Inline Styles (For Demonstration Only)

### Concept

* Inline styles are used here to keep all code visible in one place.
* In real applications, it is better to use the `StyleSheet` API for:

  * Better performance
  * Cleaner code
  * Easier maintenance

---

## 3. Creating a Styled Box

### Goal

Add a new `View` element styled as a blue square.

### Step 2: Add a Box with Background Color and Size

#### Code

-------------------code----------------------
import { View } from "react-native";

export default function App() {
  return (
    <View
      style={{
        flex: 1,
        justifyContent: "center",
        alignItems: "center",
      }}
    >
      <View
        style={{
          backgroundColor: "dodgerblue",
          width: 100,
          height: 100,
        }}
      />
    </View>
  );
}
-------------------code----------------------

### Result

* Displays a blue square centered on the screen.

---

## 4. Adding Border Styles

### Concept

React Native allows customization of borders using:

* `borderWidth`
* `borderColor`
* `borderRadius`

### Step 3: Add Border Width and Color

### Result

* A blue box with a thick royal blue border.

---

### Step 4: Add Rounded Corners

#### Code

-------------------code----------------------
<View
  style={{
    backgroundColor: "dodgerblue",

    height: 100,

  }}
/>
-------------------code----------------------

### Result

* The box now has rounded corners.

---

## 5. Customizing Individual Borders

### Concept

Borders can be customized individually for each side:

* `borderTopWidth`
* `borderTopLeftRadius`
* `borderTopRightRadius`
* `borderBottomLeftRadius`
* `borderBottomRightRadius`

---

### Step 5: Make the Top Border Thicker

#### Code

-------------------code----------------------
<View
  style={{
    backgroundColor: "dodgerblue",
    width: 100,
    height: 100,
    borderWidth: 10,
    borderColor: "royalblue",

  }}
/>
-------------------code----------------------

### Result

* The top border becomes thicker than the other sides.

---

### Step 6: Modify Only One Corner Radius

#### Code

-------------------code----------------------

  style={{
    backgroundColor: "dodgerblue",
    width: 100,
    height: 100,

  }}

-------------------code----------------------

### Result

* The top-left corner becomes heavily rounded.
* Each corner can be styled independently.

---

## 6. Creating a Perfect Circle

### Concept

To create a circle:

* `borderRadius` must be at least half of width and height.
* If width and height are 100, radius must be at least 50.

---

### Step 7: Convert Box into Circle

#### Code

-------------------code----------------------
<View
  style={{
    backgroundColor: "dodgerblue",
    width: 100,
    height: 100,
    borderWidth: 10,
    borderColor: "royalblue",
    borderRadius: 50,
  }}
/>
-------------------code----------------------

### Result

* The square becomes a perfect circle.

---

## 7. Important Notes

### Independent Pixels

* React Native uses independent pixels instead of device pixels.
* Ensures consistent appearance across different screen densities.

### Best Practice Reminder

* Inline styles are used only for learning.
* Production apps should use `StyleSheet.create()`.

*** 3- Shadows ***
### Lecture Notes: Shadows in React Native

---

## 1. Overview of Shadows

Shadows help create depth and visual hierarchy in user interfaces. In React Native, shadow implementation differs between iOS and Android.

* iOS supports detailed shadow customization.
* Android supports shadows using a single property called `elevation`.

In this lecture, styling continues using the same centered blue box.

---

## 2. Base Setup (Blue Box in Center)

### Step 1: Create the Container and Box

#### Code

-------------------code----------------------
import { View } from "react-native";

export default function App() {
  return (
    <View
      style={{
        flex: 1,
        justifyContent: "center",
        alignItems: "center",
      }}
    >
      <View
        style={{
          backgroundColor: "dodgerblue",
          width: 100,
          height: 100,
          borderWidth: 10,
          borderColor: "royalblue",
          borderRadius: 50,
        }}
      />
    </View>
  );
}
-------------------code----------------------

---

# iOS Shadow Properties

To apply shadows on iOS, at least three properties must be used.

---

## 3. Shadow Color

### Concept

Defines the color of the shadow.

### Step 2: Add Shadow Color

#### Code

-------------------code----------------------
shadowColor: "gray",
-------------------code----------------------

---

## 4. Shadow Offset

### Concept

Controls the position or direction of the shadow.

It accepts an object with two properties:

* `width` moves the shadow horizontally
* `height` moves the shadow vertically

---

### Step 3: Add Shadow Offset

#### Code

-------------------code----------------------
shadowOffset: {
  width: 10,
  height: 10,
},
-------------------code----------------------

### Result

* Moves shadow diagonally to the bottom-right.

---

### Step 4: Modify Offset Position

#### Example 1: Move Shadow Vertically Only

-------------------code----------------------
shadowOffset: {
  width: 0,
  height: 10,
},
-------------------code----------------------

#### Example 2: Move Shadow to the Opposite Direction

-------------------code----------------------
shadowOffset: {
  width: -10,
  height: 10,
},
-------------------code----------------------

---

## 5. Shadow Opacity

### Concept

Controls how dark or transparent the shadow appears.

* Value ranges from `0` to `1`
* `0` means invisible
* `1` means fully visible

---

### Step 5: Add Shadow Opacity

#### Code

-------------------code----------------------
shadowOpacity: 0.5,
-------------------code----------------------

---

## 6. Shadow Radius

### Concept

Controls the softness or blur of the shadow edges.

---

### Step 6: Add Shadow Radius

#### Code

-------------------code----------------------
shadowRadius: 10,
-------------------code----------------------

### Result

* Creates a softer and more natural shadow.

---

## 7. Full iOS Shadow Example

#### Code

-------------------code----------------------
<View
  style={{
    backgroundColor: "dodgerblue",
    width: 100,
    height: 100,
    borderWidth: 10,
    borderColor: "royalblue",
    borderRadius: 50,
    shadowColor: "gray",
    shadowOffset: {
      width: 0,
      height: 10,
    },
    shadowOpacity: 0.5,
    shadowRadius: 10,
  }}
/>
-------------------code----------------------

---

# Android Shadow Property

Android handles shadows differently and provides limited customization.

---

## 8. Elevation Property

### Concept

* `elevation` adds depth and shadow automatically.
* Accepts a numeric value.
* Higher values produce stronger shadows.
* Android does not support custom shadow color, offset, opacity, or radius.

---

### Step 7: Add Elevation

#### Code

-------------------code----------------------
elevation: 20,
-------------------code----------------------

---

## 9. Full Android Shadow Example

#### Code

-------------------code----------------------
<View
  style={{
    backgroundColor: "dodgerblue",
    width: 100,
    height: 100,
    borderWidth: 10,
    borderColor: "royalblue",
    borderRadius: 50,
    elevation: 20,
  }}
/>
-------------------code----------------------

---

# 10. Cross-Platform Shadow Example

To support both iOS and Android, combine all shadow properties.

---

## Step 8: Apply Cross-Platform Shadow

#### Code

-------------------code----------------------
import { View } from "react-native";

export default function App() {
  return (
    <View
      style={{
        flex: 1,
        justifyContent: "center",
        alignItems: "center",
      }}
    >
      <View
        style={{
          backgroundColor: "dodgerblue",
          width: 100,
          height: 100,
          borderWidth: 10,
          borderColor: "royalblue",
          borderRadius: 50,

          // iOS Shadow
          shadowColor: "gray",
          shadowOffset: {
            width: 0,
            height: 10,
          },
          shadowOpacity: 0.5,
          shadowRadius: 10,

          // Android Shadow
          elevation: 20,
        }}
      />
    </View>
  );
}
-------------------code----------------------

---

## 11. Important Differences Between Platforms

### iOS

* Supports detailed shadow control:

  * Color
  * Offset
  * Opacity
  * Blur radius

### Android

* Supports only `elevation`
* Limited customization options
* Shadow appearance depends on system rendering

---

## 12. Best Practices

* Use combined styling to ensure cross-platform consistency.
* Test shadow appearance on both platforms.
* Use moderate shadow values to avoid visual clutter.

---

## Summary

This lecture introduced:

* Shadow styling in React Native.
* iOS shadow properties and customization.
* Android elevation-based shadow system.
* Cross-platform shadow implementation.
* Understanding visual depth using shadows.

*** 4- Paddings and Margins ***
### Lecture Notes: Padding and Margin in React Native

---

## 1. Overview

Padding and margin are essential layout properties used to control spacing in user interfaces.

### Key Difference

* **Padding**: Space inside a component (between the component border and its content).
* **Margin**: Space outside a component (between the component and other components).

Understanding these concepts is fundamental for building properly spaced and visually balanced layouts.

---

# Part 1: Understanding Padding

---

## 2. Base Setup (Blue Box)

We continue using the blue box as the main container and place another box inside it.

---

### Step 1: Create the Blue Box with Inner Content

#### Code

-------------------code----------------------
import { View } from "react-native";

export default function App() {
  return (
    <View
      style={{
        flex: 1,
        justifyContent: "center",
        alignItems: "center",
      }}
    >
      <View
        style={{
          backgroundColor: "dodgerblue",
          width: 100,
          height: 100,
        }}
      >
        <View
          style={{
            backgroundColor: "gold",
            width: 50,
            height: 50,
          }}
        />
      </View>
    </View>
  );
}
-------------------code----------------------

### Result

* The gold box is placed directly against the edges of the blue box.
* There is no internal spacing.

---

## 3. Applying General Padding

### Concept

Padding adds space inside a component.

---

### Step 2: Add Padding to the Blue Box

#### Code

-------------------code----------------------
<View
  style={{
    backgroundColor: "dodgerblue",
    width: 100,
    height: 100,
    padding: 20,
  }}
>
-------------------code----------------------

### Result

* Adds 20 pixels of space inside the blue box on all sides.
* The gold box moves inward.

---

## 4. Horizontal Padding

### Concept

`paddingHorizontal` applies padding to both left and right sides.

---

### Step 3: Add Horizontal Padding

#### Code

-------------------code----------------------
paddingHorizontal: 10,
-------------------code----------------------

### Important Note

* This overrides left and right values from the general `padding`.

---

## 5. Vertical Padding

### Concept

`paddingVertical` applies padding to top and bottom sides.

---

### Step 4: Example

#### Code

-------------------code----------------------
paddingVertical: 10,
-------------------code----------------------

---

## 6. Individual Side Padding

### Available Properties

* `paddingLeft`
* `paddingRight`
* `paddingTop`
* `paddingBottom`

---

### Step 5: Override Left Padding

#### Code

-------------------code----------------------
paddingLeft: 30,
-------------------code----------------------

### Result

* Left padding becomes 30 pixels.
* Overrides `paddingHorizontal` for the left side.

---

# Part 2: Understanding Margin

---

## 7. Creating a Second Box

Now we add another box outside the blue box to demonstrate margin.

---

### Step 6: Add a Tomato Colored Box

#### Code

-------------------code----------------------
<View
  style={{
    backgroundColor: "tomato",
    width: 100,
    height: 100,
  }}
/>
-------------------code----------------------

### Result

* The tomato box appears directly next to the blue box.
* No external spacing exists between them.

---

## 8. Applying Margin

### Concept

Margin adds space outside a component.

---

### Step 7: Add Margin to the Tomato Box

#### Code

-------------------code----------------------
margin: 20,
-------------------code----------------------

### Result

* Adds 20 pixels of spacing around the tomato box.
* Creates separation between UI elements.

---

## 9. Margin Variations

### Available Margin Properties

* `marginHorizontal`
* `marginVertical`
* `marginLeft`
* `marginRight`
* `marginTop`
* `marginBottom`

These behave the same way as padding but apply outside the component.

---

# 10. Full Demonstration Code

-------------------code----------------------
import { View } from "react-native";

export default function App() {
  return (
    <View
      style={{
        flex: 1,
        justifyContent: "center",
        alignItems: "center",
      }}
    >
      <View
        style={{
          backgroundColor: "dodgerblue",
          width: 100,
          height: 100,
          padding: 20,
          paddingHorizontal: 10,
          paddingLeft: 30,
        }}
      >
        <View
          style={{
            backgroundColor: "gold",
            width: 50,
            height: 50,
          }}
        />
      </View>

      <View
        style={{
          backgroundColor: "tomato",
          width: 100,
          height: 100,
          margin: 20,
        }}
      />
    </View>
  );
}
-------------------code----------------------

---

# 11. Padding vs Margin Summary

| Property | Purpose                 | Affects                     |
| -------- | ----------------------- | --------------------------- |
| Padding  | Space inside component  | Content positioning         |
| Margin   | Space outside component | Distance between components |

---

# 12. Priority Rules

More specific padding or margin properties override general ones.

Example Priority:

1. `paddingLeft`
2. `paddingHorizontal`
3. `padding`

---

# 13. Best Practices

* Use padding to control internal layout and spacing.
* Use margin to separate components.
* Avoid excessive spacing values.
* Keep layout consistent across components.

---

## Summary

This lecture covered:

* The difference between padding and margin.
* How to apply internal spacing using padding.
* How to apply external spacing using margin.
* Horizontal, vertical, and individual side spacing.
* Property override behavior.

*** 5- Styling Text ***
### Lecture Notes: Styling Text in React Native

---

## 1. Overview

React Native provides a `Text` component for displaying and styling text. Text styling allows developers to control font appearance, spacing, alignment, and decoration.

Important Concept:

* Text styling properties apply only to the `Text` component.
* Unlike CSS in web development, React Native does not support style inheritance across components.

---

# Part 5: Important React Native Concept

---

## 13. No Style Inheritance

### Explanation

In web CSS:

* Text styles can be applied to parent elements and inherited by children.

In React Native:

* Style inheritance does not exist for components like `View`.
* Text styling must be applied directly to the `Text` component.

---

### Example (Invalid Styling on View)

#### Code

-------------------code----------------------
<View style={{ fontSize: 30 }}>
  <Text>Hello</Text>
</View>
-------------------code----------------------

### Result

* No font size change occurs.
* `fontSize` is not supported on `View`.

---

# 14. Ensuring Consistent Text Styling

Since style inheritance is not available:

* Developers typically create reusable styled text components.
* Centralized styling improves consistency across screens.
