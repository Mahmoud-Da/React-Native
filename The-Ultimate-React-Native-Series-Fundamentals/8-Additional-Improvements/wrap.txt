## 2. Real-World Scenario Simulation

You are asked to imagine the following situation:

1. You just got hired as a React Native developer.
2. You are assigned to an existing project.
3. The project was built by another developer.
4. The project contains:

   * Several issues that must be fixed.
   * A new feature that must be implemented.
5. You are expected to work independently, similar to a real production environment.

This simulates a “worst-case” but realistic scenario where:

* You did not write the original code.
* You must understand someone else’s structure and logic.
* You must debug and extend the project.

## 4. Learning Goal

The purpose of this section is to:

## 5. Recommended Workflow

When completing the exercises:

1. Carefully analyze the existing codebase.
2. Identify bugs before making changes.
3. Understand the architecture and data flow.
4. Implement fixes step-by-step.
5. Add the new feature cleanly without breaking existing functionality.
6. Test thoroughly.
7. Refactor if necessary.

After completing all exercises:

* Return to the instructor’s solution.
* Compare approaches.
* Identify differences.
* Learn alternative patterns or improvements.

---

## 6. Key Takeaways

* Real-world development often involves working with unfamiliar code.
* Debugging and code comprehension are critical skills.
* Clean implementation and careful testing are essential.
* Practical exercises are more valuable than passive learning.
