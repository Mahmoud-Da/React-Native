# Getting User Input in React Native

## 1. Introduction

In this section, we learn how to get input from users in React Native. The section covers three main topics:

1. Input components available in React Native core
2. Building custom styled text input boxes
3. Building a cross-platform picker component from scratch

These components allow users to type text, select options, and interact with your app.

---

# 2. React Native Core Input Components

React Native provides built-in components to collect user input.

The most important ones are:

* TextInput → for typing text
* Switch → for true/false input
* Button → for triggering actions
* Picker (community package) → for selecting from a list

The most commonly used input component is TextInput.

---

# 8. Full Final Example Code

-------------------code----------------------
import React, { useState } from "react";
import {
  View,
  TextInput,
  StyleSheet,
  Text,
  TouchableOpacity,
  Modal,
} from "react-native";

export default function App() {
  const [name, setName] = useState("");
  const [category, setCategory] = useState(null);
  const [modalVisible, setModalVisible] = useState(false);

  return (
    <View style={styles.container}>
      
      <TextInput
        style={styles.input}
        placeholder="Enter your name"
        value={name}
        onChangeText={(text) => setName(text)}
      />

      <TouchableOpacity
        style={styles.picker}
        onPress={() => setModalVisible(true)}
      >
        <Text>
          {category ? category : "Select Category"}
        </Text>
      </TouchableOpacity>

      <Modal visible={modalVisible} animationType="slide">
        <View style={styles.modalContainer}>

          <Text
            style={styles.option}
            onPress={() => {
              setCategory("Books");
              setModalVisible(false);
            }}
          >
            Books
          </Text>

          <Text
            style={styles.option}
            onPress={() => {
              setCategory("Movies");
              setModalVisible(false);
            }}
          >
            Movies
          </Text>

          <Text
            style={styles.option}
            onPress={() => {
              setModalVisible(false);
            }}
          >
            Close
          </Text>

        </View>
      </Modal>

    </View>
  );
}

const styles = StyleSheet.create({

  container: {
    flex: 1,
    justifyContent: "center",
  },

  input: {
    borderWidth: 1,
    borderColor: "#ccc",
    padding: 10,
    margin: 10,
    borderRadius: 5,
  },

    padding: 15,
    margin: 10,
    borderRadius: 5,
  },

  modalContainer: {
    flex: 1,

  },

  },

# Extracting Default Styles into a Central Configuration File in React Native

## 1. Introduction

Previously, default text styles such as font, size, and color were defined inside multiple components like AppText and AppTextInput. This caused duplication and made maintenance difficult. The solution is to extract these styles into a single configuration file so all components share the same default styles.

## 2. Problem: Duplicate Styles

Example of duplicated styles inside components:

-------------------code----------------------
textInput: {
  fontSize: 18,
  color: colors.dark,
  ...Platform.select({
    ios: { fontFamily: "Avenir" },
    android: { fontFamily: "Roboto" },
  }),
}
-------------------code----------------------

Problems:

* Same code repeated in multiple files
* Hard to update globally
* Poor maintainability
  Best practice: Use a single source of truth.

## 3. Step 1: Create Global Styles File

Create a new file:
config/styles.js

## 4. Step 2: Define Default Styles

Import dependencies and export default styles:

-------------------code----------------------
import { Platform } from "react-native";
import colors from "./colors";
export default {
  colors,
  text: {
    color: colors.dark,
    fontSize: 18,
    ...Platform.select({
      ios: { fontFamily: "Avenir" },
      android: { fontFamily: "Roboto" },
    }),
  },
};
-------------------code----------------------

This file now contains default styles and colors.

## 5. Step 3: Use Default Styles in AppText

  }

-------------------code----------------------

-------------------code----------------------

  return <Text style={defaultStyles.text}>{children}</Text>;

# React Native Switch Component – Clean Structured Notes

## 1. Introduction to Switch Component

The **Switch** component in React Native is used to capture a **boolean value**, meaning:

* True / False
* On / Off
* Enabled / Disabled

It is commonly used for:

* Settings (notifications on/off)
* Toggles (dark mode on/off)
* Feature enable/disable

Important: The Switch looks different on iOS and Android because each platform follows its own design language.

---

## 2. Import the Correct Switch Component

React Native provides its own Switch component.

There is another Switch in react-native-gesture-handler, but you should use the one from react-native.

### Correct Import

-------------------code----------------------
import { Switch } from "react-native";
-------------------code----------------------

---

## 3. Step 1: Create a Boolean State Variable

The Switch needs a state variable to store its value.

Use the useState hook.

### Code

-------------------code----------------------
import React, { useState } from "react";
-------------------code----------------------

Inside your component:

-------------------code----------------------
const [isNew, setIsNew] = useState(false);
-------------------code----------------------

Explanation:

* isNew → current value (true or false)
* setIsNew → function to update the value
* false → initial value

---

## 4. Step 2: Bind the State to the Switch

Use the value prop.

This connects the Switch UI to your state.

### Code

-------------------code----------------------
<Switch value={isNew} />
-------------------code----------------------

Now the switch reflects the state.

---

## 5. Step 3: Handle Switch Changes

When the user toggles the switch, you must update the state.

Use:

onValueChange

This function receives the new boolean value.

### Code

-------------------code----------------------
<Switch
  value={isNew}
  onValueChange={(newValue) => setIsNew(newValue)}
/>
-------------------code----------------------

Explanation:

* newValue is true or false
* setIsNew updates the state
* UI updates automatically

This is called a Controlled Component.

---

## 6. Complete Example (Basic)

-------------------code----------------------
import React, { useState } from "react";
import { View, Switch } from "react-native";

function App() {

  const [isNew, setIsNew] = useState(false);

  return (

    <View>

      <Switch
        value={isNew}
        onValueChange={(newValue) => setIsNew(newValue)}
      />

    </View>

  );

}

export default App;
-------------------code----------------------

---

## 7. How Switch Looks on iOS vs Android

iOS:

* Smooth animation
* Modern design
* Positioned normally

Android:

* Different visual style
* Usually aligned to the right
* Matches Android design system

This difference is normal and expected.

React Native follows native platform design.

---

## 8. How Switch Works Internally (Step-by-Step)

Step 1:

Step 2:

onValueChange fires

Step 3:

newValue is received

Step 4:

State is updated

Step 5:

UI re-renders automatically

---

Correct:

-------------------code----------------------

-------------------code----------------------

Always use useState.

Use clear naming:

isNew
-------------------code----------------------

x

-------------------code----------------------
