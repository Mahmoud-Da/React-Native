# Building Forms in React Native — Structured Notes

## 1. Introduction

In this section, the goal is to take the app to the next level by adding **forms**. Forms allow users to input and submit data.

You will build three main screens:

1. Login Screen
2. Register Screen
3. Add Listing Screen

To achieve this, you will use two important libraries:

* Formik → for managing form state
* Yup → for validating form data

You will also learn how to create reusable form components.

---

# 2. Why Forms Need Special Handling

Forms are more complex than normal components because they must handle:

* User input
* Validation
* Errors
* Submission
* Field state (touched, dirty, etc.)

Without a library, managing all of this manually becomes messy.

Example of manual form handling (not recommended):

-------------------code----------------------
const [email, setEmail] = useState("");
const [password, setPassword] = useState("");

<TextInput
   value={email}
   onChangeText={setEmail}
/>

<TextInput
   value={password}
   onChangeText={setPassword}
/>
```

Problems:

* Hard to scale
* Hard to validate
* Hard to manage many fields

Solution: Use Formik

---

Formik is a popular library for building forms in React and React Native.

Formik helps you manage:

Formik replaces manual useState for forms.

# 8. Basic Yup Validation Example

## Step 1: Import Yup

-------------------code----------------------
import * as Yup from "yup";
-------------------code----------------------

---

## Step 2: Create Validation Schema

-------------------code----------------------
const validationSchema = Yup.object().shape({

   email: Yup.string()
      .required()
      .email(),

   password: Yup.string()
      .required()
      .min(4)

});
-------------------code----------------------

---

## Step 3: Attach Schema to Formik

-------------------code----------------------
<Formik
   initialValues={{ email: "", password: "" }}
   onSubmit={(values) => console.log(values)}
   validationSchema={validationSchema}
>
-------------------code----------------------

Now Formik validates automatically.

# 11. Full Final Code Example

This is a complete working example.

-------------------code----------------------
import React from "react";
import { View, TextInput, Button } from "react-native";
import { Formik } from "formik";
import * as Yup from "yup";

const validationSchema = Yup.object().shape({

   email: Yup.string()
      .required("Email is required")
      .email("Invalid email"),

   password: Yup.string()
      .required("Password is required")
      .min(4, "Password too short")

});

export default function LoginScreen() {

   return (

      <View style={{ padding: 20 }}>

         <Formik

            initialValues={{
               email: "",
               password: ""
            }}

            validationSchema={validationSchema}

            onSubmit={(values) => {

               console.log(values);

            }}

         >

            {({

               handleChange,
               handleSubmit,
               values

            }) => (

               <>

                  <TextInput

                     placeholder="Email"

                     value={values.email}

                     onChangeText={handleChange("email")}

                     style={{
                        borderWidth: 1,
                        marginBottom: 10,
                        padding: 10
                     }}

                  />

                  <TextInput

                     placeholder="Password"

                     value={values.password}

                     onChangeText={handleChange("password")}

                     secureTextEntry

                     style={{
                        borderWidth: 1,
                        marginBottom: 10,
                        padding: 10
                     }}

                  />

                  <Button

                     title="Login"

                     onPress={handleSubmit}

                  />

               </>

            )}

         </Formik>

      </View>

   );

}
```
