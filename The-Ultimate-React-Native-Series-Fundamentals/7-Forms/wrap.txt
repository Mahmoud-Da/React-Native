In this section, the goal is to take the app to the next level by adding **forms**. Forms allow users to input and submit data.

1. Login Screen

# 2. Why Forms Need Special Handling

Forms are more complex than normal components because they must handle:

* User input
* Validation
* Errors
* Submission
* Field state (touched, dirty, etc.)

Without a library, managing all of this manually becomes messy.

Example of manual form handling (not recommended):

-------------------code----------------------
const [email, setEmail] = useState("");
const [password, setPassword] = useState("");

<TextInput
   value={email}
   onChangeText={setEmail}
/>

<TextInput
   value={password}
   onChangeText={setPassword}
/>
-------------------code----------------------

Problems:

* Hard to scale
* Hard to validate
* Hard to manage many fields

Solution: Use Formik

# 11. Full Final Code Example

This is a complete working example.

-------------------code----------------------
import React from "react";
import { View, TextInput, Button } from "react-native";
import { Formik } from "formik";
import * as Yup from "yup";

const validationSchema = Yup.object().shape({

   email: Yup.string()
      .required("Email is required")
      .email("Invalid email"),

   password: Yup.string()
      .required("Password is required")
      .min(4, "Password too short")

});

export default function LoginScreen() {

   return (

      <View style={{ padding: 20 }}>

         <Formik

            initialValues={{
               email: "",
               password: ""
            }}

            validationSchema={validationSchema}

            onSubmit={(values) => {

               console.log(values);

            }}

         >

            {({

               handleChange,
               handleSubmit,
               values

            }) => (

               <>

                  <TextInput

                     placeholder="Email"

                     value={values.email}

                     onChangeText={handleChange("email")}

                     style={{
                        borderWidth: 1,
                        marginBottom: 10,
                        padding: 10
                     }}

                  />

                  <TextInput

                     placeholder="Password"

                     value={values.password}

                     onChangeText={handleChange("password")}

                     secureTextEntry

                     style={{
                        borderWidth: 1,
                        marginBottom: 10,
                        padding: 10
                     }}

                  />

                  <Button

                     title="Login"

                     onPress={handleSubmit}

                  />

               </>

            )}

         </Formik>

      </View>

   );

}
-------------------code----------------------

*** 3- Building Better Forms with Formik ***
# Using Formik in Login Screen — Structured Notes

This lecture introduces **Formik** and replaces manual form state handling with Formik. This makes forms cleaner, scalable, and easier to maintain.

---

# 1. Problem With Manual Forms

Previously, you used `useState` to manage form inputs:

Example:

-------------------code----------------------
const [email, setEmail] = useState("");
const [password, setPassword] = useState("");
-------------------code----------------------

Problems with this approach:

As the number of fields increases:

* More state variables needed
* More event handlers needed
* Harder to validate inputs
* More complex code

Example with 5 fields:

-------------------code----------------------
const [field1, setField1] = useState("");
const [field2, setField2] = useState("");
const [field3, setField3] = useState("");
const [field4, setField4] = useState("");
const [field5, setField5] = useState("");
-------------------code----------------------

This becomes difficult to manage.

Solution: Use Formik

---

# 2. What is Formik

Formik is a popular library that:

* Tracks form state automatically
* Handles input changes
* Handles submission
* Supports validation

Main benefit:

Removes need for useState for form fields.

Formik manages everything internally.

# Form Validation with Yup and Formik — Structured Notes

This lecture explains how to add **form validation** using **Yup**, and integrate it with **Formik** to validate email and password fields.

---

# 1. Why Validation is Needed

Validation ensures users enter correct data.

Examples:

* Email must be valid format
* Password must have minimum length
* Required fields cannot be empty

Without validation:

* Invalid data can be submitted
* Security and usability problems occur

Solution: Use Yup with Formik

Formik has built-in support for Yup.

---

# 15. Full Final Code

LoginScreen.js

-------------------code----------------------
import { Formik } from "formik";
import {
  Image,
  StyleSheet
} from "react-native";
import * as Yup from "yup";
import AppButton from "../components/AppButton";
import AppText from "../components/AppText";
import AppTextInput from "../components/AppTextInput";
import Screen from "../components/Screen";

const validationSchema = Yup.object().shape({
  email: Yup.string()
    .required()
    .email()
    .label("Email"),
  password: Yup.string()
    .required()
    .min(4)
    .label("Password")
});

function LoginScreen() {
  return (
    <Screen style={styles.container}>
      <Image
        source={require("../assets/logo-red.png")}
        style={styles.logo}
      />
      <Formik
        initialValues={{
          email: "",
          password: ""
        }}
        validationSchema={validationSchema}
        onSubmit={(values) => console.log(values)}
      >

        {({
          handleChange,
          handleSubmit,
          errors
        }) => (
          <>
            <AppTextInput
              icon="email"
              placeholder="Email"
              autoCapitalize="none"
              autoCorrect={false}
              keyboardType="email-address"
              textContentType="emailAddress"
              onChangeText={handleChange("email")}
            />
            <AppText style={{ color: "red" }}>
              {errors.email}
            </AppText>
            <AppTextInput
              icon="lock"
              placeholder="Password"
              autoCapitalize="none"
              autoCorrect={false}
              secureTextEntry
              textContentType="password"
              onChangeText={handleChange("password")}
            />
            <AppText style={{ color: "red" }}>
              {errors.password}
            </AppText>
            <AppButton
              title="Login"
              onPress={handleSubmit}
            />
          </>
        )}
      </Formik>
    </Screen>
  );
}

const styles = StyleSheet.create({
  container: {
    padding: 10
  },
  logo: {
    width: 80,
    height: 80,
    alignSelf: "center",
    marginTop: 50,
    marginBottom: 20
  }
});

export default LoginScreen;
