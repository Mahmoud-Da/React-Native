*** 3- Calling APIs Using ApiSauce ***
# 1. Overview of the Lecture

This lecture introduces **API communication** in React Native using the library:

-------------------code----------------------
apisauce
-------------------code----------------------

`apisauce` is:

* A wrapper around Axios
* Simpler to use
* Provides standardized error handling
* Makes API calls cleaner

The lecture also introduces the beginning of an API layer architecture.

---

# 2. What is apisauce?

`apisauce` is a library built on top of Axios.

It simplifies:

* API requests
* Error handling
* Response processing

---

# 3. Why Use apisauce Instead of Axios Directly?

The instructor prefers `apisauce` because:

---

## 3.1 Promises Always Resolve

With Axios:

-------------------code----------------------
try {
  const response = await axios.get(...);
} catch (error) {
  // handle error
}
-------------------code----------------------

With apisauce:

-------------------code----------------------
const response = await api.get("/listings");

if (!response.ok) {
  console.log(response.problem);
}
-------------------code----------------------

No `try-catch` needed.

---

## 3.2 Standardized Errors

apisauce provides consistent error types such as:

-------------------code----------------------
CLIENT_ERROR
SERVER_ERROR
CONNECTION_ERROR
TIMEOUT_ERROR
NETWORK_ERROR
-------------------code----------------------

This makes debugging easier.

---

## 3.3 Cleaner API Layer

apisauce encourages organized API architecture.

---

-------------------code----------------------

# 12. Response Object

apisauce returns a response object.

Example:

-------------------code----------------------
const response = await apiClient.get("/listings");
-------------------code----------------------

---

## Important Properties

| Property         | Purpose                   |
| ---------------- | ------------------------- |
| response.ok      | True if request succeeded |
| response.data    | Response data             |
| response.problem | Error type                |

---

# 13. Handling Success

-------------------code----------------------
if (response.ok) {
  console.log(response.data);
}
-------------------code----------------------

---

# 14. Handling Errors

-------------------code----------------------
if (!response.ok) {
  console.log(response.problem);
}
-------------------code----------------------

No try-catch required.

---

# 15. Common Error Types

---

## CLIENT_ERROR

Problem with request.

Examples:

* 400
* 404

---

## SERVER_ERROR

Backend server issue.

Examples:

* 500

---

## CONNECTION_ERROR

Cannot connect to backend.

Usually:

* Wrong IP
* Backend not running

---

## TIMEOUT_ERROR

Server took too long to respond.

---

## NETWORK_ERROR

General network issue.

---

# 16. Example Full API Call

const getListings = async () => {
  const response = await apiClient.get("/listings");

  if (!response.ok) {
    console.log(response.problem);

  }

  console.log(response.data);
};
