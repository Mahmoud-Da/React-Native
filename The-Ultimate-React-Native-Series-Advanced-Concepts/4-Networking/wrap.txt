*** 3- Calling APIs Using ApiSauce ***
# 1. Overview of the Lecture

This lecture introduces **API communication** in React Native using the library:

-------------------code----------------------
apisauce
-------------------code----------------------

`apisauce` is:

* A wrapper around Axios
* Simpler to use
* Provides standardized error handling
* Makes API calls cleaner

The lecture also introduces the beginning of an API layer architecture.

---

# 2. What is apisauce?

`apisauce` is a library built on top of Axios.

It simplifies:

* API requests
* Error handling
* Response processing

---

# 3. Why Use apisauce Instead of Axios Directly?

The instructor prefers `apisauce` because:

---

## 3.1 Promises Always Resolve

With Axios:

-------------------code----------------------
try {
  const response = await axios.get(...);
} catch (error) {
  // handle error
}
-------------------code----------------------

With apisauce:

-------------------code----------------------
const response = await api.get("/listings");

if (!response.ok) {
  console.log(response.problem);
}
-------------------code----------------------

No `try-catch` needed.

---

## 3.2 Standardized Errors

apisauce provides consistent error types such as:

-------------------code----------------------
CLIENT_ERROR
SERVER_ERROR
CONNECTION_ERROR
TIMEOUT_ERROR
NETWORK_ERROR
-------------------code----------------------

This makes debugging easier.

---

## 3.3 Cleaner API Layer

apisauce encourages organized API architecture.

---

*** 4- Creating an API Layer ***
# 1. Overview of the Lecture

This lecture explains why API calls should not be written directly inside React components.

The instructor introduces:

* Proper architecture
* Separation of concerns
* API layer design
* Encapsulation of HTTP logic

The main goal is:

-------------------code----------------------
Keep UI components focused only on UI
-------------------code----------------------

---

# 2. The Problem With Direct API Calls in Components

Many beginners write code like this directly inside screens:

-------------------code----------------------
const response = await client.get("/listings");
-------------------code----------------------

This is considered bad architecture.

---

# 3. Why This is Bad Practice

---

## 3.1 Hardcoded Endpoints

Bad:

-------------------code----------------------
"/listings"
-------------------code----------------------

Problems:

* Difficult to maintain
* Easy to mistype
* Hard to rename later

---

## 3.2 UI Components Know Too Much

Components should NOT know:

* HTTP methods
* Endpoints
* Headers
* API structure
* Request configuration

---

## 3.3 Violates Separation of Concerns

A React component should only handle:

* UI rendering
* User interaction
* Display logic

Not backend communication details.

---

# 4. Responsibility of a React Component

A React component should only say:

-------------------code----------------------
Give me listings
-------------------code----------------------

or

-------------------code----------------------
Save this listing
-------------------code----------------------

It should not know:

* How requests are sent
* Which endpoint is used
* Whether request is GET or POST

---

# 5. What is an API Layer?

An API layer is a separate abstraction between:

* UI components
* Backend server

---

## UI Component

Talks to:

-------------------code----------------------
API Layer
-------------------code----------------------

---

## API Layer

Handles:

* Endpoints
* HTTP methods
* Headers
* API configuration

---

# 6. Architecture Flow

---

## Without API Layer

-------------------code----------------------
Screen -> HTTP Request -> Server
-------------------code----------------------

Problem:

* Tight coupling
* Hard maintenance

---

## With API Layer

-------------------code----------------------
Screen -> API Layer -> Server
-------------------code----------------------

Better:

* Cleaner architecture
* Easier maintenance
* Reusable logic

---

* server error

# 12. Full useApi Hook

-------------------code----------------------
import { useState } from "react";

export default function useApi(apiFunc) {
  const [data, setData] = useState([]);
  const [error, setError] = useState(false);
  const [loading, setLoading] = useState(false);

  const request = async (...args) => {
    setLoading(true);

    const response = await apiFunc(...args);

    setLoading(false);

    if (!response.ok) {
      setError(true);
      return;
    }

    setError(false);
    setData(response.data);
  };

  return {
    data,
    error,
    loading,
    request,
  };
}
-------------------code----------------------

import client from "./client";

const endpoint = "/listings";

const getListings = () => client.get(endpoint);

const addListing = (listing) => {
  const data = new FormData();

  data.append("title", listing.title);
  data.append("price", listing.price);
  data.append("categoryId", listing.category.value);
  data.append("description", listing.description);

  listing.images.forEach((image, index) => {

      name: "image" + index,
      type: "image/jpeg",
      uri: image,

      JSON.stringify(listing.location)

# 4. Understanding `onUploadProgress`

`onUploadProgress` is called repeatedly while the request uploads.

-------------------code----------------------

-------------------code----------------------

* `total` → total bytes

# 5. Calculate Upload Percentage

-------------------code----------------------
progress.loaded / progress.total
-------------------code----------------------

Example:

-------------------code----------------------
0.5
-------------------code----------------------

This means:

-------------------code----------------------txt
50% uploaded
-------------------code----------------------

---

## Why Keep It Between 0 and 1?

Many progress bar components expect values like:

-------------------code----------------------txt
0 → empty
1 → complete
-------------------code----------------------

So we do NOT multiply by 100.

# 12. Full Final Code

## `api/listings.js`

-------------------code----------------------
import client from "./client";

const endpoint = "/listings";

const getListings = () => client.get(endpoint);

const addListing = (listing, onUploadProgress) => {
  const data = new FormData();

  data.append("title", listing.title);
  data.append("price", listing.price);
  data.append("categoryId", listing.category.value);
  data.append("description", listing.description);

  listing.images.forEach((image, index) => {
    data.append("images", {
      name: "image" + index,
      type: "image/jpeg",
      uri: image,
    });
  });

  if (listing.location)
    data.append("location", JSON.stringify(listing.location));

  return client.post(endpoint, data, {
    onUploadProgress: (progress) =>
      onUploadProgress(progress.loaded / progress.total),
  });
};

export default {
  getListings,
  addListing,
};
