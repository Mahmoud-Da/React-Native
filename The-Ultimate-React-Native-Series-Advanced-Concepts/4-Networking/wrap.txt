*** 1- Introduction ***
# 1. Overview of the Section

This section introduces **backend integration** in a React Native app.

Until now:

* Listings were hardcoded locally
* Data existed only inside the app

Now the app will:

* Fetch listings from a backend server
* Upload listings to the server
* Show upload progress
* Display animations after successful uploads

This is the transition from a UI-only app to a real full-stack mobile application.

---

# 2. Main Goals of This Section

By the end of this section, the app will be able to:

1. Connect to a backend server

3. Post new listings
4. Upload images
5. Show upload progress
6. Display success animations
7. Handle API communication properly

# 12. Important Notes

---

## Network Requests Are Asynchronous

API requests take time.

You must handle:

* Loading states
* Errors
* Retries

---

## Backend May Fail

Always expect:

* Timeout
* No internet
* Server errors

Never assume success.

---

## Avoid Hardcoded Data

This section replaces static arrays with real server data.

---

## Separate API Logic

Do NOT place API code directly inside screens.

Good structure:

-------------------code----------------------
api/
-------------------code----------------------

instead of:

-------------------code----------------------
ListingsScreen.js
-------------------code----------------------
