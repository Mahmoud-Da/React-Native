*** 2- Setting Up the Backend ***
# 1. Overview of the Lecture

This lecture explains how to set up the backend server for the React Native app.

The backend:

* Is a Node.js project
* Provides fake API endpoints
* Serves listings and images
* Simulates a real backend server

This backend is used for:

* Fetching listings
* Uploading listings
* Serving images

---

# 2. Purpose of the Backend

The backend acts as the server for the mobile app.

It will:

* Store listings temporarily
* Return listings through APIs
* Handle uploads
* Serve images

# 8. DO NOT Use localhost

Important:

-------------------code----------------------
localhost will NOT work on mobile devices
-------------------code----------------------

Why?

Because:

* Emulator/device is separate from your computer
* `localhost` inside phone means the phone itself

---

# 9. Use Your Machine IP Address

Instead of:

-------------------code----------------------
localhost
-------------------code----------------------

Use:

-------------------code----------------------
192.168.x.x
-------------------code----------------------

Example:

-------------------code----------------------
"http://192.168.0.12:9000/assets/"
-------------------code----------------------

---

# 13. Fake Backend Explained

This backend:

* Does NOT use a database
* Stores data in memory only

Meaning:

* Fast setup
* Easy for learning
* No MongoDB setup required

---

# 14. Important Limitation

Data is temporary.

If you restart the server:

-------------------code----------------------
All created listings disappear
-------------------code----------------------

Because data exists only in memory.

---

# 15. Why Use a Fake Backend?

Benefits:

* Faster learning
* Simpler setup
* Focus on React Native
* No database configuration needed

This is common in tutorials and prototypes.
