## 2. Topics Covered in the Advanced Section

* Sensors

Navigation is a fundamental feature of mobile apps. It allows users to move between different screens.

In this section you will learn how to:

* Structure multi-screen applications
* Navigate between screens
* Pass data between screens
* Manage navigation stacks

Typical navigation patterns include:

* Stack navigation
* Tab navigation
* Drawer navigation

These patterns help organize complex apps into **clean and maintainable structures**.

---

### 2.3 Networking

Most real-world applications communicate with a backend server.

Networking topics include:

* Sending HTTP requests
* Fetching data from APIs
* Handling responses
* Managing loading states
* Handling errors

This enables your app to interact with services such as:

* Databases
* Authentication systems
* External APIs

---

### 2.4 Offline Support

Good mobile apps continue to function even when internet connectivity is unstable or unavailable.

Offline support techniques include:

* Local caching
* Local databases
* Synchronizing data when the device reconnects

This improves **user experience and reliability**.

---

### 2.5 Authentication and Authorization

Many applications require user accounts.

Key concepts include:

**Authentication**

**Authorization**

* Controlling access to resources
* Determining what actions a user is allowed to perform

Common features implemented in this section:

* Login systems
* Token management
* Protected screens

---

### 2.6 Push Notifications

Push notifications allow applications to communicate with users even when the app is closed.

Topics include:

* Sending notifications
* Receiving notifications
* Handling notification actions
* Managing notification permissions

Push notifications are often used for:

* Messages
* Updates
* Reminders
* Alerts

---

### 2.7 App Distribution

The final stage of development is **delivering the app to users**.

This section covers:

* Running apps on real devices
* Preparing builds
* Publishing apps to app stores

Platforms typically include:

* Apple App Store
* Google Play Store

This process involves:

* App signing
* Build configuration
* Store submission requirements

# 3. Required React Knowledge

## 3.1 Familiarity with React Hooks

Students should be **fairly comfortable using React Hooks**.

You do not need to be an expert, but you should understand the basics.

Key hooks required for this course include:

### useState

Used to manage component state.

Example:

-------------------code----------------------
import React, { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  );
}
-------------------code----------------------

### useEffect

Used to perform side effects such as data fetching or subscriptions.

Example:

-------------------code----------------------
import React, { useEffect } from "react";

useEffect(() => {
  console.log("Component mounted");
}, []);
-------------------code----------------------

Students should understand:

* When to use `useState`
* When to use `useEffect`
* Basic hook behavior

---

## 3.2 Understanding React Context

Students should also understand the **React Context API**, which allows data sharing across components without prop drilling.

Basic example:

-------------------code----------------------
import React, { createContext } from "react";

const AuthContext = createContext();
-------------------code----------------------

Context is often used for:

* Authentication state
* Global settings
* Shared data across screens

This course will rely on Context for **state management across the application**.

---

# 4. Required JavaScript Knowledge

These include:

## 4.1 Arrow Functions

Example:

-------------------code----------------------

## 4.2 Spread Operator

Used to copy or merge objects and arrays.

Example:

-------------------code----------------------
const user = { name: "John" };

-------------------code----------------------

## 4.3 Promises

Promises represent asynchronous operations.

Example:

-------------------code----------------------
fetch(url)
  .then(response => response.json())
  .then(data => console.log(data));
-------------------code----------------------

## 4.4 Async and Await

This course will rely heavily on **async/await** for asynchronous operations.

Example:

-------------------code----------------------

}
-------------------code----------------------

Students should understand:

* What asynchronous programming is
* How `async` functions work
* How `await` pauses execution until a promise resolves

# VS Code Setup for React Native Development — Code Snippets

## 1. Introduction

In this lecture, the instructor explains how to **improve development speed in React Native using code snippets in Visual Studio Code (VS Code)**.

Although any code editor can be used, the instructor recommends **VS Code** because it supports powerful customization features such as **user-defined code snippets**.

Code snippets allow developers to **quickly generate common code templates**, reducing repetitive typing and improving productivity.

---

# 2. Recommended Editor

The instructor uses:

* **Visual Studio Code (VS Code)**

However, students are free to use **any editor they prefer**.

If using VS Code, it is recommended to install and configure the provided **React Native function component snippet**.

---

# 3. Purpose of the Snippet

The snippet allows developers to **automatically generate a React Native function component template**.

Instead of manually writing the component structure, developers can simply type:

-------------------code----------------------
rnfc
-------------------code----------------------

Then VS Code will generate a **basic React Native component structure**.

This template includes:

* React import
* React Native imports
* Function component
* View container
* Stylesheet
* Export statement

---

# 4. Generated Component Template

When typing `rnfc`, the following structure will be generated automatically:

-------------------code----------------------
import React from 'react';
import { View, StyleSheet } from 'react-native';

function ComponentName(props) {
  return (
    <View style={styles.container}></View>
  );
}

const styles = StyleSheet.create({
  container: {}
});

export default ComponentName;
-------------------code----------------------

The component name will automatically match the **file name** because of the variable:

-------------------code----------------------
${TM_FILENAME_BASE}
-------------------code----------------------

This helps maintain **consistent naming between files and components**.

---

# 5. Installing the Snippet in VS Code

Follow these steps to install the snippet.

## Step 1 — Open VS Code Settings

In the top menu:

1. Click **Code** (on macOS) or **File** (on Windows)
2. Select **Preferences**
3. Click **User Snippets**

---

## Step 2 — Open JavaScript Snippets File

Search for:

-------------------code----------------------
javascript.json
-------------------code----------------------

This file stores **all custom snippets used in JavaScript files**.

Important note:

Do not delete any existing snippets that may already exist in this file.

---

## Step 3 — Add the Provided Snippet

Copy the following snippet into the `javascript.json` file.

-------------------code----------------------
{
  "Function Component": {
    "prefix": "rnfc",
    "body": [
      "import React from 'react';",
      "import { View, StyleSheet } from 'react-native';",
      "",
      "function ${TM_FILENAME_BASE}(props) {",
      "  return (",
      "    <View style={styles.container}>$0</View>",
      "  );",
      "}",
      "",
      "const styles = StyleSheet.create({",
      "  container: {}",
      "});",
      "",
      "export default ${TM_FILENAME_BASE};"
    ]
  }
}
-------------------code----------------------

---

# 6. How the Snippet Works

The snippet contains three main parts.

## 6.1 Snippet Name

-------------------code----------------------
"Function Component"
-------------------code----------------------

This is simply the **display name of the snippet**.

---

## 6.2 Prefix (Shortcut)

-------------------code----------------------
"prefix": "rnfc"
-------------------code----------------------

This is the **shortcut typed in the editor** to activate the snippet.

Typing:

-------------------code----------------------
rnfc
-------------------code----------------------

and pressing **Enter or Tab** expands the template.

---

## 6.3 Body

The `body` contains the **code that will be inserted automatically**.

Example:

-------------------code----------------------
"body": [
  "import React from 'react';",
  "import { View, StyleSheet } from 'react-native';"
]
-------------------code----------------------

Each string represents **one line of code**.

---

# 7. Snippet Variables

VS Code snippets support special variables.

### ${TM_FILENAME_BASE}

This variable automatically inserts the **current file name without extension**.

Example:

If the file name is:

-------------------code----------------------
LoginScreen.js
-------------------code----------------------

The component will automatically become:

-------------------code----------------------
function LoginScreen()
-------------------code----------------------

---

### $0

This defines the **final cursor position after the snippet expands**.

In this snippet:

-------------------code----------------------
<View style={styles.container}>$0</View>
-------------------code----------------------

The cursor will appear **inside the View**, ready for additional content.

---

# 8. Benefits of Using Snippets

Using snippets provides several advantages:

### Faster Development

Reduces repetitive typing.

### Consistent Structure

Ensures all components follow the same structure.

### Cleaner Code

Encourages a standardized component layout.

### Improved Productivity

Developers can focus on logic instead of writing boilerplate code.

---

# 9. Best Practices

* Do not delete existing snippets inside `javascript.json`.
* Add new snippets **below existing entries**.
* Save the file after adding the snippet.
* Use clear naming conventions for component files.

Example:

-------------------code----------------------
LoginScreen.js
ListingDetailsScreen.js
MessagesScreen.js
-------------------code----------------------

This ensures the snippet generates properly named components.

---

# 10. Key Takeaways

* VS Code supports **custom code snippets** that improve development speed.
* The `rnfc` snippet generates a **React Native function component template**.
* The snippet should be added to the **javascript.json user snippets file**.
* `${TM_FILENAME_BASE}` automatically uses the file name as the component name.
* Snippets help maintain **clean, consistent, and efficient React Native code**.
